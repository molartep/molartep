<summary>About this profile</summary>

The portrait is real ASCII text converted from my own headshot, rendered as colored SVG text for light and dark GitHub themes. Its plain-text version is in [assets/portrait.txt](assets/portrait.txt).

Public GitHub stats refresh daily through GitHub Actions. Repos counts owned public repositories. Commits counts unique commits attributed to my account on the default branches of my owned public repositories, excluding forks. Lines of Code on GitHub is cumulative added text lines minus deleted text lines from those commits; merge diffs and binary files are excluded. Green `++` shows additions and red `--` shows deletions. These totals describe that public history, rather than every contribution across GitHub or a current source-only code inventory. The card records its last successful update in UTC.

To regenerate the cards without network access:

```sh
python3 scripts/build_profile.py
```

To refresh public stats and regenerate:

```sh
python3 scripts/build_profile.py --refresh
```

No third-party stats service or personal access token is required. Profile text lives in `scripts/build_profile.py`; portrait characters and source color samples live in `assets/`. See [maintenance notes](MAINTENANCE.md) to replace the portrait.

Terminal-style presentation inspired by [Andrew Grant's profile](https://github.com/Andrew6rant/Andrew6rant). This implementation and portrait were created specifically for this profile.
